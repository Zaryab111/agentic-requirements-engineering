# MediQueue Developer Rules

## Code Style & Rules
- All requirement files must live in `requirements/` and follow the JSON Schema.
- Use EARS syntax (WHEN, WHILE, IF, WHERE) with the keyword "shall".
- Avoid vague words: fast, slow, quickly, extremely, user-friendly, intuitive, robust.

## Useful Commands
- Lint requirements: `python scripts/lint-requirements.py`
